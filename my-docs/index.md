## Current position

AOS already has:

- a durable control plane
- a swarm execution layer
- a sales/support ops loop
- finance and billing visibility
- scheduling and retry support
- social posting via Upload-Post

What it does **not** yet have is a first-class project object that the user can create and use as the operating boundary for a startup.

## What this section is for

- which capabilities are already real
- which capabilities still need to be built before AOS can claim autonomous operation
