# B2B SaaS Pricing Page

This project implements a responsive pricing page for a B2B SaaS product, featuring three distinct service tiers: Starter, Professional, and Enterprise.

## Project Structure

```
project/
├── index.html — Main HTML file for the pricing page.
├── style.css — Stylesheet for the pricing page.
└── README.md — Project overview and viewing instructions.
```

## How to View the Page

To view the pricing page, simply open the `index.html` file in your web browser. No special server setup is required as it's a static HTML page.

1.  Navigate to the `project/` directory.
2.  Double-click on `index.html` (or open it with your preferred web browser).

## Features

*   **Three Tiers**: Clearly defined Starter, Professional, and Enterprise pricing plans.
*   **Responsive Design**: Adapts to various screen sizes for optimal viewing on desktop, tablet, and mobile devices.
*   **Clear Call-to-Actions**: Prominent buttons for signing up or contacting sales.
*   **Feature Comparison**: Easy-to-read lists of features included in each plan.
*   **Modern UI**: Clean and professional design using the Inter font.

## Technologies Used

*   HTML5
*   CSS3

## Success Metric

The primary success metric for this pricing page is to achieve a 15% increase in click-through rate on the "Sign Up" or "Contact Sales" buttons within the first month of deployment.
